# Mass Evaluation Quick Start

This quick start summarizes how to run the mass evaluation skeletons.

Steps:
1. Ensure `mass_evaluation/` dependencies (Python 3.11+, aiohttp, numpy) are installed.
2. Run `1_corpus_scanner.py` to generate corpus inventory.
3. Run `2_extract_targets.py` to map sections.
4. Run `3_serve_corpus.py` to host corpus locally.
5. Run `4_mass_synthetic_traffic.py` to generate synthetic traffic.
6. Run `5_master_batch_pipeline.py` to analyze results.
7. Run `6_generate_report.py` to produce CSV report.

Each script is a skeleton and includes TODOs—expand as needed.
